# Threads 插件 實作計畫（2026-10-16）

> **給執行者：** 本計畫由同一個 Claude Code 對話用 superpowers:executing-plans 逐工作執行；每個工作有自己的驗證，做完第 5 個工作要停下來給 Jeff 載入測試。規格在 `docs/設計.md`，DOM 事實在 `docs/DOM調查.md`。

**目標：** 做出 Threads 網頁用的 Chrome 插件：文案收錄、互動率顯示、高流量主題收集、影片下載，外加每日高流量主題串的桌面排程。

**架構：** MV3，純 JS 無打包。`lib.js` 放純函式（可用 `node --test` 測），`content.js` 做 DOM，`page-hook.js` 在主世界攔 GraphQL，`background.js` 存檔與匯出，`popup.*` 看清單與設定。

**技術：** Chrome Manifest V3、chrome.storage.local、chrome.downloads、MutationObserver、Node 26 內建 test runner（只測 lib.js）。

## 全域限制
- 只在 `https://www.threads.com/*` 生效。
- 本插件插的節點一律帶 `data-tp="…"`；不改、不刪其他插件（`[data-kolr-injected]`、`[data-jk-vocab]`）或 Threads 的節點。
- 選擇器全部集中在 `content.js` 的 `SEL`。
- console 訊息前綴 `[Threads插件]`。
- 匯出檔固定在 `~/Downloads/Threads收錄/`：`收錄.json`、`收錄.md`、`高流量.json`、`趨勢話題.json`、`觀看數.json`，全部覆寫。
- 影片存 `~/Downloads/Threads影片/<作者>_<代碼>.mp4`，只存本機。
- 不是 git 專案，沒有 commit 步驟；每個工作做完寫一行到 `00-交接/紀錄/` 當日工作日誌。

## 檔案
| 檔 | 負責 |
|---|---|
| `manifest.json` | MV3 宣告：content_scripts（lib.js、content.js 隔離世界；page-hook.js `world: MAIN`）、background、action popup、permissions `storage`、`downloads` |
| `lib.js` | 純函式，無 DOM、無 chrome：`parseCount`、`computeRatios`、`levelOf`、`mergePost`、`extractPostsFromGraphql`、`postsToMarkdown`、`isHot`、`DEFAULT_SETTINGS`。瀏覽器下掛 `globalThis.TP`，Node 下 `module.exports` |
| `tests/lib.test.js` | `node --test tests/` |
| `page-hook.js` | 掛 XHR `loadend`，呼叫 `TP.extractPostsFromGraphql`，`window.postMessage({type:'tp-posts', posts})` |
| `content.js` | `SEL`、`parsePost`、`hookStore`、`scanner`、`renderBar`、頁面抄錄（/search、/insights）、與 background 的訊息 |
| `background.js` | `store`（四集合＋settings）、`exporter`（debounce 3 秒覆寫）、`videoDownloader`、訊息路由 |
| `popup.html`、`popup.js`、`style.css` | 彈窗與注入樣式 |
| `README.md` | 安裝、用法、改門檻、捷徑指令 |
| `docs/每日排程提示詞.md` | 桌面排程用的提示詞 |

訊息協定（content → background，`chrome.runtime.sendMessage`）：
- `{type:'save', post}` → 收錄 upsert；`{type:'unsave', code}`；`{type:'isSaved', codes:[…]}` → `{saved:{code:true}}`
- `{type:'hot', post}` → 高流量 upsert
- `{type:'trends', date, items}`；`{type:'views', items:{code:{views, seen_at}}}`
- `{type:'getSettings'}` → settings；`{type:'setSettings', settings}`
- `{type:'getViews'}` → views；`{type:'download', url, filename}`；`{type:'export'}`（手動匯出）；`{type:'summary'}`（彈窗用）

### 工作 3：content.js 讀貼文與收錄鈕
**檔案：** 建 `content.js`、填 `style.css`。
**消費：** `TP.*`、訊息協定。
- [ ] `SEL`：
  ```js
  const SEL = {
    post: '[data-pressable-container="true"]',
    postLink: 'a[href*="/post/"]',
    authorLink: 'a[href^="/@"]',
    time: 'time[datetime]',
    textLeaf: '[dir="auto"]',
    actionTitle: 'svg title',
    titles: { like:['讚','收回讚'], reply:['回覆','已回覆'], repost:['轉發'], share:['分享'] },
    profileLink: 'a[aria-label="個人檔案"], [role="link"][aria-label="個人檔案"]',
    trendHeading: '最新趨勢話題', trendCount: /([\d.]+\s*[千萬]?)\s*則貼文/,
    insightsCard: 'a[href^="/insights/post/"]', viewsLabel: '觀看次數',
  };
  ```
- [ ] `parsePost(el)`：取 `postLink` → code、author（`/@x/post/CODE`）、url；`time.datetime`；動作列：對每個 `svg title`，文字在 `titles` 某類 → `closest('[role="button"]')` 內的葉 span 數字 → `parseCount`；沒 span → 0；四類一個都沒找到 → 回 `null`。內文：`textLeaf` 葉節點中，位於 time 之後、第一個純數字之前的，`\n` 相接。topic：容器內第一個葉文字若符合 `/^(超夯|精選|熱門)[：:]\s*(.+)$/` 取第 2 組。回 `{code,url,author,posted_at,topic,text,likes,replies,reposts,shares,views:null,exact:false,has_video:!!el.querySelector('video')}`。
- [ ] `hookStore`：`new Map()`；`window.addEventListener('message', e => e.source===window && e.data?.type==='tp-posts' && e.data.posts.forEach(p=>hookStore.set(p.code,p)))`；收到後對畫面上已渲染且 code 相同的貼文重跑 `renderBar`。
- [ ] `scanner`：`MutationObserver` 盯 `document.body`，`requestIdleCallback` 節流（最多每 300ms 一次）掃 `SEL.post` 中沒有 `data-tp-seen` 的 → `parsePost` → `mergePost(dom, hookStore.get(code))` → `computeRatios` → `renderBar`。渲染後 `el.dataset.tpSeen = code`。
- [ ] `renderBar(el, post)`：找動作列（任一動作 title 的 `closest('[role="button"]').parentElement`），在其後插或更新 `div[data-tp="bar"]`，本工作只放「收錄」鈕：`button[data-tp="save"]`，文字「收錄」／「已收錄 ✓」。點擊 → `sendMessage({type:'save'|'unsave', …})`。載入時批次 `isSaved` 決定初始狀態。
- [ ] 把 `settings.me` 讀側欄 `profileLink` 的 href（`/@sojei1989` → `sojei1989`），不同時 `setSettings`。
- [ ] `style.css`：bar 用 Threads 的字級 12px、灰字；鈕小、圓角、透明底、細框；`[data-tp="save"].on` 填色。
