# Threads 插件 設計（2026-10-16 定案；同日五功能完成並驗收）

Threads（threads.com）網頁用的 Chrome 插件，Jeff 自用。五個功能依序做：文案收錄 → 互動率顯示 → 高流量主題收集 → 影片下載 → 每日高流量主題串。前三個共用同一套「讀貼文資料」程式。每做完一個，Jeff 在 chrome://extensions 載入未封裝項目測過才做下一個。

## 已知事實（來自 `DOM調查.md`）
- Threads 無公開數據 API。畫面上每篇貼文有讚、回覆、轉發、分享四個數字（簡寫如「3.5 萬」）。
- Threads 自己用 XHR `POST /api/graphql` 拿貼文，回應裡有精確數字、完整內文、影片 mp4 直連。content script 讀不到，要掛在頁面主世界。**首頁第一批貼文不走 XHR，嵌在 `<script type="application/json" data-sjs>` 裡**，page-hook 也要讀。
- 別人的貼文沒有觀看數（影片貼文內頁頁首有「N 次瀏覽」，本版不用）。自己的貼文觀看數只在 `/insights` 洞察報告頁。
- 搜尋頁 `/search` 有官方「最新趨勢話題」清單（標題、AI 摘要、則數、連結）。
- Chrome 插件不能直接寫專案資料夾；用 `chrome.downloads` 覆寫到 **Chrome 下載資料夾**底下的 `Threads收錄/`（實測 Jeff 的 Chrome 下載到 `JKRACING-車宮社群產文/`，不是 ~/Downloads），專案的 `收錄/` 用捷徑指過去。Chrome「下載前詢問儲存位置」要關，不然每次匯出跳存檔視窗。
- Jeff 已裝 KOL Radar（`[data-kolr-injected]`）和一個字彙插件（`[data-jk-vocab]`），本插件的節點都加 `data-tp` 前綴，不碰它們的。

## 方案選擇
讀貼文資料用**混合**：DOM 為主（定位貼文、插鈕、讀畫面數字；沒有攔截也能動），GraphQL 攔截為輔（精確數字、完整內文、影片網址），兩邊用貼文代碼 `code` 對起來。
捨棄純 DOM（影片拿不到網址、數字是簡寫）與純攔截（第一批預載可能漏、改格式整個掛）。

## 架構
```
Projects/Threads插件/
  manifest.json      MV3；content_scripts 只匹配 https://www.threads.com/*
  content.js         隔離世界主程式：掃貼文、插鈕、互動率、收錄、高流量、抄趨勢與觀看數
  page-hook.js       world: MAIN：攔 /api/graphql 回應 → window.postMessage({type:'tp-posts', posts:[...]})
  background.js      service worker：收訊息、存 chrome.storage.local、匯出、影片下載
  popup.html/.js     彈窗：收錄總數與最近 5 筆、今日高流量篇數與話題數、「匯出」鈕、設定
  style.css
  README.md          安裝、用法、改門檻
  docs/設計.md、docs/DOM調查.md
  收錄/  → 捷徑 ~/Downloads/Threads收錄/
  每日/  排程產出 YYYY-MM-DD.md
  00-交接/
```

### 單元與介面
| 單元 | 做什麼 | 輸入 → 輸出 | 依賴 |
|---|---|---|---|
| `SEL`（content.js 開頭） | 所有選擇器與文字常數集中一處 | — | — |
| `parsePost(el)` | 從一個 `[data-pressable-container]` 讀出貼文 | DOM 節點 → `Post` 或 `null`（不是貼文就 null） | SEL |
| `hookStore` | page-hook 丟來的精確資料，以 code 為鍵 | `window.message` → `Map<code, HookPost>` | page-hook.js |
| `mergePost(domPost, hookPost)` | 合併：攔到的數字、內文、影片蓋過 DOM 的 | → `Post` | — |
| `ratios(post)` | 算回覆率、轉發率、分享率與顏色等級 | `Post` → `{reply, repost, share, level:{...}}` | settings |
| `renderBar(el, post)` | 在動作列下插一行比例＋鈕（冪等：已插過就更新） | — | ratios |
| `scanner` | MutationObserver＋節流，對新出現的貼文跑 parse→merge→render→hot | — | 以上 |
| `pageScrapers` | 在 `/search` 抄趨勢話題、在 `/insights` 抄觀看數 | DOM → 訊息給 background | SEL |
| background `store` | 讀寫 chrome.storage.local 四個集合＋settings | message → storage | — |
| background `exporter` | 任一集合改了，3 秒內把對應檔覆寫到 Downloads | storage → chrome.downloads | — |
| background `videoDownloader` | 下載 mp4 | `{url, filename}` → chrome.downloads | — |

### 資料
`Post`（四個集合共用）：
```json
{"code":"DeiVj3iiP-a",
 "url":"https://www.threads.com/@joman_electric/post/DeiVj3iiP-a",
 "author":"joman_electric",
 "posted_at":"2026-10-16T01:19:11.000Z",
 "topic":"特斯拉",
 "text":"最新🆕🆕🆕第三Part\n特斯拉全新跑車發佈…",
 "likes":1239,"replies":89,"reposts":26,"shares":1583,
 "views":null,
 "ratios":{"reply":0.072,"repost":0.021,"share":1.28},
 "has_video":true,
 "videos":[{"url":"https://…mp4","width":720,"height":1280}],
 "exact":true,
 "saved_at":"2026-10-16T10:40:00+08:00",
 "note":""}
```
- `topic`：動態裡貼文上方的主題標頭（「超夯：特斯拉」取冒號後）；沒有就 null。
- `views`：只有自己的貼文、而且抄過洞察報告才有。
- `exact`：true＝數字來自攔截；false＝畫面簡寫換算（「3.5 萬」→35000）。
- `videos`：只在攔到時有；匯出到收錄.json 時保留，收錄.md 不放。

chrome.storage.local：
| 鍵 | 型別 | 說明 |
|---|---|---|
| `saved` | `{code: Post}` | 文案收錄，Jeff 手按 |
| `hot` | `{code: Post}` | 高流量，自動；讚 ≥ `hotLikes` 或回覆 ≥ `hotReplies`；超過 500 筆刪 saved_at 最舊的 |
| `trends` | `{"YYYY-MM-DD": [{title, summary, count, url, seen_at}]}` | 趨勢話題，開搜尋頁自動抄，同日覆寫 |
| `views` | `{code: {views, seen_at}}` | 自己貼文觀看數，開洞察報告自動抄 |
| `settings` | 見下 | |

`settings` 預設：
```json
{"replyGreen":0.05,"replyYellow":0.02,
 "repostGreen":0.03,"repostYellow":0.01,
 "shareGreen":0.5,"shareYellow":0.2,
 "minLikes":20,
 "hotLikes":1000,"hotReplies":100,
 "me":""}
```
`me` 是自己的帳號，content.js 從側欄「個人檔案」連結讀到就寫回。

### 匯出檔（`~/Downloads/Threads收錄/`，都覆寫）
- `收錄.json`：`{"exported_at":…, "posts":[Post…]}`，saved_at 新的在前。
- `收錄.md`：給 threads-funnel 步驟 1 讀。格式：
  ```
  # Threads 收錄（插件匯出，2026-10-16 10:41）

  ## @joman_electric · 2026-10-16 09:19 · 讚 1,239 回覆 89 轉發 26 分享 1,583 · 回覆率 7% 轉發率 2% 分享率 128%
  https://www.threads.com/@joman_electric/post/DeiVj3iiP-a
  主題：特斯拉｜收錄：2026-10-16 10:40
  > 最新🆕🆕🆕第三Part
  > 特斯拉全新跑車發佈…
  ```
- `高流量.json`：`{"exported_at":…, "posts":[Post…]}`。
- `趨勢話題.json`：`trends` 原樣。
- `觀看數.json`：`views` 原樣。
匯出用 `chrome.downloads.download({url: blob, filename: "Threads收錄/收錄.json", conflictAction: "overwrite", saveAs: false})`。改動後 debounce 3 秒、只匯有變的檔。
`Projects/Threads插件/收錄` 是捷徑：`ln -s ~/Downloads/Threads收錄 收錄`。threads-funnel 的 SKILL.md 步驟 1 加一句：「插件收錄檔在 `~/Claude/Projects/Threads插件/收錄/收錄.md`」。

## 功能行為
### 1. 文案收錄
- 動作列右側加「收錄」小鈕（`button[data-tp="save"]`）；按下→「已收錄 ✓」，再按→取消。
- 存的是 `mergePost` 的結果；內文以攔截的完整 caption 為準，沒有就用畫面文字（`[dir=auto]` 介於時間與第一個數字之間的段落，用換行接）。
- 彈窗：總數、最近 5 筆（作者＋內文前 30 字＋刪除鈕）、「匯出」鈕（手動再匯一次）、「開啟資料夾說明」。

### 2. 互動率顯示
- 動作列下方一行（`div[data-tp="bar"]`）：「回覆率 7% · 轉發率 2% · 分享率 128%」；每項依門檻標綠／黃／灰；讚 < `minLikes` 顯示「樣本小」灰字不標色。
- 作者 = `settings.me` 時多顯示「觀看 7,126」；`views` 沒有就「觀看 —」並 title 提示「開洞察報告頁更新」。
- 數字來源是簡寫時（`exact:false`）比例後加「≈」。
- 不動 KOL Radar 的節點；本插件節點都在動作列之後、不插進動作列內。

### 3. 高流量主題收集
- `scanner` 每篇跑完若達門檻就 `hot` upsert（同 code 更新數字）。
- `/search` 頁：找「最新趨勢話題」標題，往下抓所有含「則貼文」的卡片 → `trends[今天]`。
- 彈窗顯示「今天記了 N 篇高流量、M 個話題」。

### 4. 影片下載
- 攔到 `videos` 的貼文多一顆「影片」鈕；下載 `videos` 中寬度最大的，檔名 `Threads影片/<作者>_<代碼>.mp4`；多段各一檔加 `_1`、`_2`。
- 攔不到：鈕灰、title「重新整理後再試」。
- 只存本機，不做轉發、不上傳。

### 5. 每日高流量主題串
- 不在插件裡。用 Claude Code 桌面排程（scheduled-tasks），每天 09:00：
  1. 用 Chrome 開 `https://www.threads.com/search`，抄「最新趨勢話題」（標題、摘要、則數、連結）。
  2. 讀 `~/Downloads/Threads收錄/高流量.json`，取 `saved_at` 在前一天 00:00 之後的，按讚數排前 10。
  3. 寫 `Projects/Threads插件/每日/YYYY-MM-DD.md`：趨勢清單 → 高流量前 10（連結、作者、數字、比例、內文前 60 字）→ 「可寫的切角」3 條（跟 Jeff 在做的事：AI 工具、設計、接案）。
  4. 不發文、不改其他檔。
- 排程的提示詞存 `docs/每日排程提示詞.md`，建排程時照貼。

## 錯誤處理
- 選擇器全部在 `SEL`；Threads 改版只改那裡。`parsePost` 找不到動作列或貼文連結就回 null，跳過那篇，不丟例外。
- page-hook 掛失敗或回應格式變了：`hookStore` 空，`mergePost` 只用 DOM，比例後顯示「≈」。
- 匯出失敗（Downloads 權限、磁碟）：background 記到 `chrome.storage.local.lastError`，彈窗頂端紅字顯示。
- 所有 console 訊息前綴 `[Threads插件]`。
- 不碰其他插件的節點；本插件節點 `data-tp` 開頭，重跑時先找已存在的就更新不重插。

## 測試
- 載入：Jeff 在 chrome://extensions 開「開發人員模式」→「載入未封裝項目」→ 選 `Projects/Threads插件/`。
- 每個功能做完的驗收（我用 Claude in Chrome 檢查，Jeff 看畫面）：
  1. 收錄：動態每篇貼文有「收錄」鈕；按一篇 → 彈窗出現該篇；`~/Downloads/Threads收錄/收錄.json`、`收錄.md` 出現且內容對；`Projects/Threads插件/收錄/收錄.md` 捷徑讀得到。
  2. 互動率：每篇有一行比例，顏色對門檻；自己的貼文開過洞察報告後顯示觀看數。
  3. 高流量：滑過讚 ≥1,000 的貼文後 `高流量.json` 有它；開搜尋頁後 `趨勢話題.json` 有今天。
  4. 影片：按「影片」→ `~/Downloads/Threads影片/` 出現 mp4 可播。
  5. 每日：排程跑一次 → `每日/今天.md` 存在且三段都有。
- 不寫自動化測試（純 DOM 腳本、Threads 頁面無法離線重現）；每個功能用上面的驗收清單。

## 不做
- 轉發、上傳、自動發文、自動留言。
- 別人貼文的觀看數（內頁才有，本版不抓）。
- 封裝上架；永遠用「載入未封裝項目」。
